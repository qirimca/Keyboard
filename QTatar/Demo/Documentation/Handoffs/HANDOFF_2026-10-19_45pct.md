## 11. Візуальна робота: що реально працювало

Skill device-interaction є subagent skill: прочитати SKILL.md і делегувати лише конкретну вузьку перевірку. Інші агенти без user/skill дозволу не створювати. Translation coordinator теж дозволяє/вимагає agents для локалізації.

Інструменти доступні через functions.exec / tools.mcp__xcode_tools__...; метадані схем шукати у ALL_TOOLS за точним name, не друкувати весь список. `structuredContent` зручно, але при помилці його може не бути: тоді вивести весь result, інакше отримаєте misleading undefined.

Робочий шлях:
1. BuildProject (один раз), без одночасного UI run.
2. За потреби `xcrun simctl install <UUID> '<DerivedData>/Build/Products/Debug-iphonesimulator/QTatar.app'`. Sandbox інколи дає CoreSimulatorService invalid/connection refused: це виправлялось exec_command require_escalated з вузьким prefix [xcrun,simctl], а не перевстановленням runtime.
3. `DeviceInteractionStartSession({deviceIdentifier:UUID,sessionIdentifier:"Clear Unique Name"})` для вже встановленого app. Return interactionSessionKey зберегти.
4. `DeviceInteractionSynthesize({interactSessionKey:key,activationBundleId:"crh.key.keyboard",interactionCommand:""})` → hierarchyPath + screenshotPath. Читати hierarchy/hitPoint; screenshots лише необхідні.
5. Команди Synthesize: `t x y`, `t x y 1` довге натискання, `orientation portrait/landscapeLeft`, `activationBundleId:"com.apple.Preferences"` для Settings. Координати брати з поточного hierarchy; якщо remote placeholder — дозволена оцінка screenshot після невдалого hitPoint.
6. Можна перевірити кілька відомих натискань одним command; не робити screenshots кожної літери. Для набору саме екранної клавіатури натискати keys, не використовувати hardware `sender keyboard kbd`, який обходить транслітерацію.
7. `DeviceInteractionEndSession` обов'язково наприкінці; не залишати UI session відкритою.

Проблемний шлях: StartWorkspaceSession→InstallAndRun двічі зависав на `Session initialization timed out` (хвилини); потім session missing. Fallback вище реально працював. Не повторювати нескінченно.

Глобус: у Settings→General→Keyboard→Keyboards→Add New Keyboard→QırımKey ввімкнути обидва extensions. На iPhone15Pro обидва вже були ввімкнені під час останньої перевірки. Довге натискання системного глобуса показує два імені. Додати extension програмно iOS не дозволяє.

Наявний XCUITest target QirimKeyUITests (5методів) має identifiers key.character.<text>, key.numeric/symbolic/alphabetic/shift/backspace/globe, sandbox.input, sandbox.clear, field.*, theme.*. GetTestList→RunSomeTests; тести різних script на iPhone можуть skip якщо обрано інший extension. Реальний зелений fullsuite ще НЕ отримано. Перший runner install падав через102MBвільного диска, користувач звільнив10GB; це вже не привід вважати всі наступні failures дисковими.
