# Як допомогти QırımKey

QırımKey — громадська ініціатива для доступного письма кримськотатарською мовою на iOS. Ми не маємо окремої команди підтримки чи великих ресурсів, тому раді будь-якій волонтерській допомозі: тестуванню, текстам, перекладам, дизайну, коду, поширенню серед рідних і знайомих.

## Де почати

1. Відкрийте вкладку **Issues** і виберіть задачу з мітками `good first issue`, `help wanted`, `documentation`, `bug` або `enhancement`.
2. Якщо проблему ще не описано, створіть issue за відповідним шаблоном.
3. Напишіть у коментарі, що хочете допомогти, і коротко опишіть пристрій, iOS-версію або навичку, з якою можете долучитися.
4. Для змін у коді відкрийте pull request і заповніть checklist у шаблоні PR.

## Волонтерські напрями

- **Тестування на пристроях:** iPhone/iPad, різні версії iOS, оновлення системи, Full Access, перемикання мов, робота клавіатури в Safari/Chrome/Telegram/Notes.
- **Мовні дані:** слова, фрази, частотні списки, приклади речень, перевірка автодоповнення й регістру літер.
- **Локалізація:** кримськотатарські, українські та англійські тексти в застосунку, README, App Store metadata.
- **UX/UI:** інструкції підключення клавіатури, onboarding, доступність, зрозумілість для не технічних користувачів.
- **Розробка:** Swift/SwiftUI, KeyboardKit, SQLite-підказки, GitHub Actions, issue triage.
- **Комунікація:** поширення проєкту, пошук тестувальників, запрошення родичів і друзів перевірити клавіатуру на реальних пристроях.

## Процес роботи в GitHub

- **Issues** — джерело правди для задач, багів і досліджень.
- **Labels**:
  - `bug` — щось не працює;
  - `enhancement` — покращення або нова можливість;
  - `documentation` — тексти, інструкції, процеси;
  - `good first issue` — задача для першого внеску;
  - `help wanted` — потрібна волонтерська допомога.
- **Priority field** у GitHub Projects допомагає виділяти термінові задачі, наприклад поломки після оновлення iOS.
- **Pull requests** мають посилатися на issue, містити короткий опис змін і результати перевірки.
- **GitHub Actions** мають запускати доступні автоматичні перевірки; ручне тестування на iOS-пристроях усе одно потрібне для клавіатурного розширення.

## Мінімальний чекліст тестування клавіатури

- Клавіатура вмикається в `Settings > General > Keyboard > Keyboards`.
- Full Access можна увімкнути, і застосунок правильно бачить цей стан.
- Клавіатура зʼявляється після перемикання мов через globe/keyboard switcher.
- Літери кримськотатарського латинського алфавіту вводяться коректно.
- `İ/ı`, `Ğ/ğ`, `Ñ/ñ`, `Ü/ü`, `Ş/ş`, `Ö/ö`, `Ç/ç` не ламаються в Safari, Chrome, Notes і месенджерах.
- Автодоповнення не змінює вже введене слово неочікувано.
- Перші літери речення й власні назви зберігають правильний регістр.
- iPad layout не прилипає до країв і не розтягує функціональні клавіші.

## Як оформлювати корисний баг-репорт

Додайте:

- модель пристрою;
- версію iOS;
- версію QırımKey;
- чи ввімкнено Full Access;
- застосунок, де помилка відтворюється;
- точні кроки;
- очікуваний і фактичний результат;
- скриншот або відео, якщо це безпечно.

Не додавайте приватні тексти, паролі, коди, листування або інші чутливі дані.
